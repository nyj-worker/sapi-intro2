# 스마트 행정혁신 연구동아리

`dist/index.html`을 직접 열거나 `dist` 폴더를 정적 호스팅에 배포합니다. 배포용 파일은 이미 준비되어 있습니다.

- `dist/index.html`: 소개, 내비게이션, 회원 테이블 구조
- `dist/app.js`: 성과물 24건, 회원 11명 및 검색·필터·메뉴 기능
- `dist/style.css`: 데스크톱, 모바일, A4 인쇄 스타일
- `dist/city.svg`: 자체 제작 도시 일러스트
- `dist/hero-3d.js`: Three.js 기반 도시와 남양주시 지도 레이어, 시점 및 애니메이션
- `dist/hero-3d.css`: 3D 장면 배치와 히어로 문구 스타일
- `dist/hero-3d.bundle.js`: 직접 파일 열기도 지원하는 배포용 스크립트
- `dist/namyangju-boundary.geojson`: 실제 남양주시 행정구역 경계
- `dist/map-sources.md`: 지도 기준 시점, 출처, 상징적 조형 안내
- `dist/interactions.css`: 섹션 진입 효과와 스크롤 진행률 Top 버튼
- `dist/members-3d.js`: 회원 테이블의 입체 받침, 조명과 마우스 기울임 (표 내용은 HTML 유지)

3D 원본을 수정한 뒤에는 `npm run build`를 실행해 배포용 스크립트를 갱신합니다. 경계 데이터가 바뀌면 먼저 `node prepare-map.mjs`를 실행합니다. Three.js는 동봉된 로컬 파일을 사용하므로 렌더링에 외부 CDN이 필요하지 않습니다. WebGL을 사용할 수 없거나 인쇄할 때는 지도와 도시 SVG를 표시합니다.

3D 인트로는 현재 기본 배율의 130%에서 시작해 5.5초 동안 천천히 회전하며 기본 배율로 돌아옵니다. 마우스 시점은 수평 약 ±14도, 수직 약 ±7도로 부드럽게 반응하며 주광원 위치도 함께 변합니다. 화면 밖에서는 애니메이션을 정지하고, 동작 줄이기 설정에서는 인트로와 자동 움직임을 생략합니다.

콘텐츠는 제공된 「동아리 주요 성과물.pdf」를 바탕으로 작성했습니다. 링크 없는 성과물 6건은 주소를 받으면 `app.js`의 해당 항목 네 번째 값에 입력하세요. 원문에서 프롬프트 학습과 단축키 학습의 주소가 동일합니다. 기본사회 정책교육 요약 자료는 사용자가 제공한 2026.09.14 강의 정보와 사이트 주소를 반영했습니다.

왼쪽 메뉴의 ‘소개서 인쇄’ 또는 브라우저 인쇄 기능을 사용하면 A4 형식으로 출력합니다. 필터 선택과 관계없이 모든 성과물을 인쇄하며 사이트 주소도 표시합니다.
